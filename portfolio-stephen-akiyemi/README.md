# Portfolio de Stephen AKIYEMI

Ce projet est un portfolio moderne conçu pour présenter les compétences, les expériences professionnelles et les informations personnelles de Stephen AKIYEMI.

## Structure du projet

Le projet est organisé comme suit :

```
portfolio-stephen-akiyemi
├── src
│   ├── assets          # Dossier pour les fichiers multimédias (images, icônes)
│   ├── components      # Composants React pour le portfolio
│   │   ├── AboutMe.jsx # Composant affichant les informations personnelles
│   │   ├── Skills.jsx  # Composant présentant les compétences en programmation
│   │   ├── Experience.jsx # Composant décrivant les expériences professionnelles
│   │   └── Header.jsx  # Composant contenant le titre et la navigation
│   ├── App.jsx         # Point d'entrée de l'application
│   └── index.js        # Point d'entrée JavaScript
├── public
│   └── index.html      # Fichier HTML principal
├── package.json        # Fichier de configuration npm
└── README.md           # Documentation du projet
```

## Installation

Pour installer les dépendances du projet, exécutez la commande suivante dans le terminal :

```
npm install
```

## Démarrage

Pour démarrer le projet en mode développement, utilisez la commande suivante :

```
npm start
```

Cela lancera l'application et l'ouvrira dans votre navigateur par défaut.

## Déploiement

Pour déployer le projet, vous pouvez utiliser des services comme Vercel, Netlify ou GitHub Pages. Assurez-vous de construire le projet avant de le déployer :

```
npm run build
```
